# Security policy

Report security issues using [GitHub private vulnerability reporting](https://github.com/Ross-cripto/remote-dev/security/advisories/new). Include the affected version, the conditions needed to reproduce the issue, and the potential impact. Use synthetic data and exclude real credentials.

Remote Dev copies source and runs development commands on the Linux server you select. Use it with projects, SSH accounts, and hosts you trust. The [user guide](docs/guide.md#source-and-sync) describes which files are synchronized and how to keep project secrets out of that source tree.
