# Remote Dev artwork

The mark connects two endpoints. It represents the Git worktree on your laptop and the services on your Linux server. The orange cable in the covers makes that connection visible.

**Product line** · Edit locally. Run on your Linux box.

| Color | Value | Use |
| --- | --- | --- |
| Graphite | `#17191A` | Dark backgrounds |
| Warm white | `#F5F1E8` | Text on graphite |
| Ember | `#FF865B` | Connections and accents on graphite |
